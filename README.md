# Olivelab

Next.js app with TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The homepage renders the same site as `/demo`.

## Deployment

- Production: [olive-lab.navnisha.tech](https://olive-lab.navnisha.tech).
- Vercel project: `olive-lab`, connected to `nav-dev-07/olive-lab` on GitHub.
- Push commits to `main` to deploy production updates automatically.
- The custom domain serves the `/demo` design at `/`; `/demo` remains available.

## Commands

- `npm run build` — create a production build.
- `npm start` — run the production server.
- `npm run lint` — run ESLint.
